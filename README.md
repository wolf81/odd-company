# odd-company

An Undertale-inspired Roblox game: walk around as your own avatar, bump into famous Roblox characters, and fight them by timing your attacks and dodging their projectiles with a heart in a box.

- **What we're building and in what order:** [`PLAN.md`](PLAN.md)
- **Rules for AI coding agents:** [`AGENTS.md`](AGENTS.md) (`CLAUDE.md` points there)
- **Original plan and UI mockups:** [`design/`](design/)

## Dev tools

| Tool | What it's for | Version / where |
|------|---------------|-----------------|
| [Roblox Studio](https://create.roblox.com/) | Runs and tests the game, publishes it to Roblox | latest |
| [Rokit](https://github.com/rojo-rbx/rokit) | Installs the command-line tools below at the exact versions in `rokit.toml` | 1.2.0 |
| [Rojo](https://rojo.space/) | Syncs the code in `src/` into Studio, live while you work | 7.7.1 (`rokit.toml`) |
| Rojo Studio plugin | The Studio side of Rojo (Plugins tab → Rojo → Connect) | installed by `rojo plugin install` |
| [luau-lsp](https://github.com/JohnnyMorganz/luau-lsp) | Type-checks the Luau code before you press Play | 1.70.1 (`rokit.toml`) |
| [VS Code](https://code.visualstudio.com/) | Code editor. Recommended extensions are in `.vscode/extensions.json`: **Luau Language Server** (`JohnnyMorganz.luau-lsp`, errors and autocomplete) and **Rojo** (`evaera.vscode-rojo`) | latest |
| [Git](https://git-scm.com/) | Version history of the code | any |

All game code is **Luau** (Roblox's typed Lua) and lives in this repo. Studio is only where it runs.

## Set up a new computer (Windows)

```sh
winget install Rojo.Rokit     # 1. install Rokit (then open a new terminal)
rokit install                 # 2. in the repo: installs Rojo and luau-lsp from rokit.toml
rojo plugin install           # 3. installs the Rojo plugin into Roblox Studio
```

Then open the folder in VS Code and accept the recommended extensions.

## Daily workflow

1. **Start the sync:** `rojo serve` in the repo folder (leave it running).
2. **Connect Studio:** open the place (`odd-company.rbxl`, or the published game), then **Plugins → Rojo → Connect**.
3. **Edit code in the repo**, never in Studio: Rojo would overwrite changes made there. Changes appear in Studio straight away.
4. **Test:** press **Play** in Studio. Messages and errors appear in the **Output** panel.
5. **Check before committing:** `bash scripts/check.sh`. It type-checks everything and makes a test build.
6. **Commit** the code with Git.
7. **Save / publish the place:** `Ctrl+S` saves `odd-company.rbxl` locally; **File → Publish to Roblox** updates the online game.

## How the repo maps into the game

`default.project.json` tells Rojo where each folder goes:

| Folder | In the game | What's there |
|--------|-------------|--------------|
| `src/shared/` | `ReplicatedStorage.Modules` | Code and data used by both sides: config, rooms, enemies, battle logic |
| `src/client/` | `StarterPlayerScripts.Client` | Runs on each player's device: camera, battle screen, menus, dodging |
| `src/server/` | `ServerScriptService.Server` | Runs on Roblox's server: builds rooms and enemies, places players |
| `assets/rooms/` | `Workspace.Rooms` | Hand-built rooms saved from Studio as `.rbxm` (none yet; rooms are built from code) |

File names decide the script type: `Name.server.luau` = Script, `Name.client.luau` = LocalScript, `Name.luau` = ModuleScript, and a folder with `init.luau` = a ModuleScript with children.

**Tuning numbers** (camera, zoom, attack timing, heart speed, player stats) are all in [`src/shared/Config.luau`](src/shared/Config.luau). Each enemy has its own file in [`src/shared/Enemies/`](src/shared/Enemies/), and dodge patterns are in [`src/client/Battle/Patterns.luau`](src/client/Battle/Patterns.luau).

## Files that are not in Git

`.gitignore` leaves out files that are built or downloaded and can always be recreated:
- `*.rbxl`: Studio place files, rebuilt from the repo
- `build/`: test builds and the downloaded Roblox type definitions
- `sourcemap.json`: generated by `rojo sourcemap` for luau-lsp
